# ANN Spectral Interpolator

This repository provides tools for spectral data inversion using Artificial Neural Networks (ANNs). It includes:

- **ANN Spectral Interpolators**: Models designed to perform spectral interpolation, enabling the estimation of spectra values at unsampled parameter space (T_eff, logg and [Fe/H]).
- **IDL Scripts**: Interactive Data Language (IDL) scripts that facilitate the inversion process, allowing for the extraction of meaningful parameters from spectral data.

## Features

- **Spectral Interpolation**: Utilizes ANNs to accurately estimate spectrum across different parameter combinations of T_eff, logg and [Fe/H].
- **Data Inversion**: Employs IDL scripts to invert spectral data, aiding in the interpretation and analysis of spectral measurements.

## Getting Started

To utilize the tools in this repository:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/niteshchandra039/ANN_spectral_Interpolator.git
   ```
2. **Navigate to the Directory**:
   ```bash
   cd ANN_spectral_Interpolator
   ```
3. **Explore the Contents**:
   - The `idl/` directory contains IDL scripts for data inversion.
   - The `trials/` directory includes examples and trials demonstrating the application of ANN spectral interpolators.

## Requirements

- **IDL**: Ensure that Interactive Data Language is installed to run the inversion scripts.
- **Python**: Some components may require Python; refer to specific scripts for dependencies.

## Usage

- **Spectral Interpolation**:
  - Utilize the ANN models provided to perform spectral interpolation on your datasets.
- **Data Inversion**:
  - Use the IDL scripts to invert spectral data and extract parameters of interest.
